# SaaS Subscription Analytics: Revenue Growth, Churn, and Retention Analysis

## Project Overview
This project analyzes synthetic SaaS subscription data using SQL, SQLite, Python, pandas, and matplotlib. The analysis focuses on revenue growth, customer churn, retention behavior, and cohort performance.

## Tools Used
- Python
- pandas
- SQLite
- SQL
- matplotlib
- Jupyter Notebook / VS Code

## Dataset Description
The dataset contains subscription-level SaaS customer data, including:
- subscription start dates
- churn information
- plan tiers
- revenue metrics
- customer lifecycle data

The dataset supports analysis of revenue trends, churn behavior, retention patterns, and cohort performance.

## Key Business Questions
- How has customer revenue grown over time?
- What are the churn trends across the business?
- Which plan tiers experience the highest churn?
- How long do customers typically remain subscribed?
- How do different customer cohorts perform over time?

## Key Findings
- New customer revenue increased significantly throughout 2024
- Churn volume increased alongside customer growth
- Enterprise customers generated the highest revenue but also contributed meaningful churn impact
- Customer lifetime varied significantly across cohorts
- Later cohorts showed signs of changing retention behavior

## Business Recommendations
- Improve onboarding for new customers
- Investigate drivers of Enterprise churn
- Monitor retention performance across cohorts
- Expand proactive customer success initiatives
